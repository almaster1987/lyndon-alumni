# Project context

Long-form background for the VTSU Lyndon Alumni Council site. The condensed version Claude reads at session start lives in `../CLAUDE.md`.

## The Council

The VTSU Lyndon Alumni Council represents alumni of, in order:

1. **Teacher Training Course** (1911) — one-year teacher training program housed on the Lyndon Institute (LI) campus
2. **Lyndon Normal School** (1920s) — expanded to a two- then three-year program; "a school within a school" at LI. Exact year of name change TBD (per Michael Thurston / Manor Vail Society, May 2026)
3. **Lyndon Teachers College** (1940s) — moved to the Theodore N. Vail estate in 1951
4. **Lyndon State College** (1961) — Vermont State Colleges system, Hornets athletics begin
5. **Northern Vermont University — Lyndon Campus** (2018) — merger with Johnson State
6. **VTSU Lyndon** (2023) — merger with Castleton + Vermont Tech to form Vermont State University

Tagline: *"Once a Hornet, Always a Hornet."*

The Council's public-facing home outside of the VTSU university site. Highlights:

- Council mission and structure
- Fall Weekend (signature Council event, late September)
- Spring Homecoming (university-sponsored, April)
- Athletic Hall of Fame
- Alumni spotlights (Jim Cantore '86, Nick Gregory '82, André Bernier '81, etc.)
- Manor Vail Society (history preservation)
- Donate CTA → Alumni Association fund (see DONATE_FLOW.md)
- Council news + newsletter signup
